# Голос из телефона — проект для Vercel

Это цельный Next.js-проект для Telegram-бота с текстом, памятью на Upstash Redis и голосовыми сообщениями.

## Что уже заложено

- Telegram webhook в `app/api/telegram/route.ts`
- команда `/start`
- команда `/reset` для очистки истории
- память последних 12 пар сообщений (30 дней)
- распознавание входящих голосовых через OpenAI
- голосовой ответ на голосовое сообщение через OpenAI TTS
- мужской голосовой пресет `onyx` и инструкция на низкую, тёплую, выразительную русскую речь
- `/proactive_on` и `/proactive_off` для согласия на редкие сообщения первым
- отдельный защищённый endpoint для регистрации webhook


## Следующий этап: актуальный интернет и новости

Это обязательное требование к следующей версии проекта; в текущей заготовке веб-поиск ещё не подключён и не должен считаться работающей функцией.

- Ассистент должен самостоятельно проверять свежую информацию в интернете практически в каждом разговоре, когда вопрос зависит от текущих фактов или проверка заметно повышает точность ответа.
- Для простых бесед, творчества и вопросов, не зависящих от текущих событий, поиск не должен запускаться без необходимости.
- Для вопросов о текущей дате и времени использовать актуальный источник системного времени, а не выводить их из обучающих данных.
- При поиске отдавать предпочтение свежим и надёжным источникам; по возможности указывать ссылки и дату публикации.
- Если поиск не сработал, источники противоречат друг другу или свежих подтверждений нет, честно сообщать об этом и не выдумывать сведения.
- Новости предоставлять по запросу. Иногда можно присылать одну короткую интересную подборку самостоятельно, но только при включённом пользователем разрешении на сообщения первым; без спама и с возможностью отключить.
- Перед выпуском этой функции выбрать и подключить поисковый инструмент/API, добавить необходимые секреты в Vercel и проверить ответы на актуальные вопросы.

## Переменные окружения Vercel

Обязательные:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из латинских букв, цифр, `_` и `-`, длиной 32–64 символа
- `TELEGRAM_SETUP_SECRET` — отдельная длинная случайная строка для одноразовой настройки webhook
- `OPENAI_API_KEY` — ключ OpenAI API
- `KV_REST_API_URL` и `KV_REST_API_TOKEN` — Upstash Redis REST URL и token

Если Upstash в проекте создал `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`, код также понимает эти имена.

Дополнительные:

- `OPENAI_CHAT_MODEL` — модель текстового ответа (по умолчанию `gpt-5-mini`)
- `OPENAI_TTS_MODEL` — модель голоса (по умолчанию `gpt-4o-mini-tts`)
- `OPENAI_TTS_VOICE` — голос (по умолчанию `onyx`)
- `PROACTIVE_MESSAGES_ENABLED` — по умолчанию `false`; не включать, пока пользователь сам не включил `/proactive_on`
- `CRON_SECRET` — секрет для защищённого cron endpoint

После изменения переменных окружения нужно сделать новый Production Deployment.

## Подключение Telegram webhook

После публикации открой в браузере адрес:

`https://ТВОЙ-ДОМЕН/api/setup?key=ТВОЙ_TELEGRAM_SETUP_SECRET`

Не отправляй эту ссылку никому и не публикуй её: в ней находится секрет настройки. После успешного ответа JSON должен содержать `"ok": true`.

Затем открой Telegram, найди своего бота и отправь `/start`.

## Голосовые

Отправь боту голосовое сообщение. Он распознает речь, ответит текстом модели и отправит ответ как голосовое сообщение. Если синтез речи временно не сработает, бот отправит текстовый ответ.

Качество и характер тембра зависят от доступных голосов и модели TTS. Голос `onyx` выбран как низкий мужской вариант; это не копия голоса ChatGPT Live.

## Сообщения первым

По умолчанию бот не пишет первым. В Telegram отправь `/proactive_on`, если хочешь разрешить редкие сообщения. `/proactive_off` отключает их. Vercel Cron настроен на один ежедневный запуск; перед включением нужно добавить `CRON_SECRET` и `PROACTIVE_MESSAGES_ENABLED=true`.

## Важно про стоимость

Текстовые ответы, распознавание голосовых и синтез речи тарифицируются отдельно по тарифам OpenAI API. Подписка ChatGPT не включает API-баланс. Можно сначала проверить текст, а затем включить голосовые функции.
